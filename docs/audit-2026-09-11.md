## Scope and limitations

Source review covered main-process services, preload/renderer integration,
provider loops, persistence, process shutdown, IPC/file/network boundaries,
MCP/plugins, scheduling, export/sharing, native dictation, and build/release
tools. Existing tests additionally exercise permissions, sandbox boundaries,
queues, rewinds, context compaction, search, extraction, and browser policies.
The retained upstream renderer and generated contracts were checked through
their pinned hashes, patch assertions, and live probes; they were not rewritten.

Passing checks establishes the tested behavior; it does not prove that every
possible defect in the repository has been eliminated. External provider
accounts, public sharing relays, OS power loss, signed release publication,
installed NSIS upgrades, and full Linux/macOS runtime matrices need their own
environments. No public release, user-profile migration, or remote push was
performed. This repository has no Git remote configured.
